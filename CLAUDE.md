# Claude instructions

Follow [AGENTS.md](AGENTS.md) for repository-wide coding and code-discovery guidance. Read [ARCHITECTURE.md](ARCHITECTURE.md) and [PROGRESS.md](PROGRESS.md) before starting work.

At the end of **every iteration**, update `PROGRESS.md` before responding. Check off **and strike through** every completed step (`- [x] ~~Completed step.~~`), keep incomplete steps unchecked, and add a dated iteration-log entry with the result, verification, blockers or decisions, and next step. If a task is only partly complete, split the checklist item so the remaining work stays visible.

When changing an architectural decision, update `ARCHITECTURE.md` in the same iteration. Do not report implementation as complete until the relevant behavior has been verified.
