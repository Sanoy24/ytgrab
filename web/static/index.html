    Browser extension

    A toolbar button and right-click item for Chrome, Edge, and Firefox that does the same.

    Get the extension

    Leave off unless YouTube keeps blocking downloads or a post needs an account. yt-dlp then uses your browser's sign-in, which YTGrab never stores. Firefox works best on Windows, and a secondary account is safer.

    This computer

    How YTGrab starts and stays working.

    Waits in the tray, ready for links and watched channels.

    Sites change often, and an old yt-dlp is the usual reason downloads stop working. New versions install between downloads.

    When YouTube changes something, fixes reach Nightly builds a day or two before a stable release. Switch back to Stable once the fix is out.

    Backup

    Your settings, watched channels, and Library in one file, for reinstalling or another computer.
